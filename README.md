# Job Application Tracker 🗂️

A Python CLI tool to track internship and job applications.
Built by Abatar Bhattarai — CIS Student @ East Texas A&M University

## What it does
- Add job applications with company, role, and status
- View all applications in one place
- Built with Python

## How to run
python3 tracker.py

## Why I built this
As an international student applying to internships, 
I needed a simple way to track my applications.
