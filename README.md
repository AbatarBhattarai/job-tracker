# Job Application Tracker 🗂️

Built by Abatar Bhattarai — CIS Student @ East Texas A&M University

## Business question

How do I keep every internship and job application — company, role, and status — in one place I can check at a glance, instead of scattered across notes and inboxes?

## Data

No dataset — this is a tool I built for my own internship search. The records are the applications I enter myself: company, role, and where each one stands.

## What I did

- Built a command-line tool in Python (`tracker.py`) for recording applications
- Each application is stored with its company, role, and status
- Added a view that lists all applications in one place

## Key finding

This project is a tool rather than an analysis, so there is no headline number. What it gives me is one complete list of my applications and their statuses — the thing I needed when my search grew past what I could track in my head.

## Recommendation

Anyone running a serious application search should keep a single tracker with a status for every application and update it the same day something changes — it is the only way follow-ups and deadlines stop slipping.
